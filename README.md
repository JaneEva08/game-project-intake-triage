# VPk04.1 — AI-разбор предложений игровых проектов

Учебный FastAPI-сервис для первичной обработки входящих предложений от игровых студий. Сохраняет оригинал сообщения, готовит русский перевод и черновик ответа, запрашивает недостающие сведения через форму и передаёт заявку сотруднику на проверку.

## Что входит в проект

- `GET /` — отдельная адаптивная страница «Для разработчиков» на русском, английском и китайском языках;
- переключатель светлой и тёмной темы с сохранением выбора в браузере;
- `POST /triage` — API приёма и анализа предложения;
- необязательная загрузка до 5 файлов к принятой заявке (PDF, презентации, документы, изображения, видео и архивы; до 20 МБ на файл и 40 МБ суммарно);
- LLM-анализ и перевод через совместимый Chat Completions API;
- безопасный fallback и ручная эскалация при ошибке модели;
- SQLite-журнал заявок и событий;
- персональная форма дополнения на английском и упрощённом китайском;
- внутренняя панель сотрудника под HTTP Basic Auth;
- отчёт и сценарии видеодемонстрации/защиты.

Проект не отправляет реальные письма и не принимает инвестиционные решения. Ответы модели и предоставленные данные проверяет сотрудник. Для демонстрации используйте только вымышленные данные.

## Запуск локально

Требуется Python 3.10+.

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
Copy-Item .env.example .env
```

Откройте `.env` локально и при необходимости задайте API-ключ и пароль панели. Не публикуйте `.env` и не показывайте его в записи. Для сценария без ключа приложение должно использовать fallback.

```powershell
uvicorn app.main:app --reload --port 8004
```

Откройте страницу для разработчиков: <http://127.0.0.1:8004/>. Обязательны студия, название игры, контактный email и описание предложения; ссылку на игру, материалы и файлы можно добавить по желанию. При отправке страница передаст текст, источник `form` и сгенерированный `client_id` в `POST /triage`. Разработчик увидит вежливое подтверждение и номер заявки; перевод, категорию и черновик ответа сервис сохраняет для внутренней проверки сотрудником. Можно прикрепить презентацию или другие материалы: разрешены PDF, PPT/PPTX, DOC/DOCX, ZIP/7Z, PNG/JPG/WEBP, MP4/MOV и TXT; максимум 5 файлов, до 20 МБ каждый и 40 МБ суммарно. Файлы хранятся локально в `data/uploads`, а сотрудник скачивает их из карточки заявки после авторизации.

Swagger для технической проверки API: <http://127.0.0.1:8004/docs>. Панель сотрудника: <http://127.0.0.1:8004/admin>.

Если порт `8004` занят, выберите другой свободный порт, например `8005`, укажите тот же порт в `PUBLIC_BASE_URL` локального `.env` и в команде запуска, затем перезапустите сервер.

## Пример запроса

Для основного пользовательского сценария откройте страницу <http://127.0.0.1:8004/> и отправьте предложение с вымышленными данными. Для прямой проверки API используйте Swagger и пример [`examples/proposal_missing_fields.json`](examples/proposal_missing_fields.json). API возвращает идентификатор заявки, перевод, тип предложения, недостающие поля и ссылку на форму. Метаданные файлов записываются в SQLite; сами файлы исключены из Git и доступны сотруднику по защищённой ссылке из карточки.
