# Покрытие VPk04.1 и границы MVP

Проверка кода и ручного сценария на 2026-11-05. Использовались вымышленные данные. Прототип запускается локально; ниже отдельно отмечены реализованные, проверенные и оставшиеся пункты.

## Учебное техническое задание

| Требование | Состояние | Примечание |
|---|---|---|
| `POST /triage` с `text`, `channel`, `client_id` | Реализовано; валидный запрос прошёл | Предел текста 1–2000 символов; ошибки схемы FastAPI возвращает как 422. Отдельная негативная проверка 422 ещё не оформлена. |
| Категории `billing`, `support`, `complaint`, `other` | Реализовано; тестовое предложение получило `other` | `business_type` отдельно распознал `incoming_offer`. |
| Черновик ответа, `confidence`, `escalate` | Реализовано; ответ получен | У неполной заявки и fallback включается ручная эскалация. |
| LLM с JSON-форматом и проверкой схемы | Проверено на одном китайском сообщении | Используется совместимый Chat Completions API с теми же базовым URL и моделью, что в VPf10. Секрет хранится только локально в `.env`. |
| Перевод на русский и сохранение оригинальных имён | Проверено на китайском сообщении | Русский текст сохранён; название студии и игры оставлены также в оригинальном виде. Другие языки требуют дополнительных примеров. |
| Fallback при сбое модели | Наблюдался в ранних прогонах | При `APIConnectionError` и ошибке проверки результата заявка сохранилась с эскалацией. Отдельный изолированный прогон с намеренно отключённым ключом не делался. |
| SQLite-журнал заявок и событий | Проверено на полном сценарии | В базе есть `triage_completed`, `form_submitted` и `staff_updated` для одного тестового обращения. |
| Персональная форма и предзаполнение | Проверено | Студия, игра и страница игры подставлены; email и материалы были отмечены как недостающие и добавлены формой. |
| Внутренняя панель сотрудника | Проверено | Basic Auth; просмотр оригинала и перевода; сохранение данных и заметки сотрудника; статус `awaiting_staff_review`. Для внешнего размещения необходим HTTPS. |
| Ограничение запросов | Реализовано в коде | Настраивается через `RATE_LIMIT_PER_MINUTE`, хранится в памяти процесса. Отдельная проверка ответа 429 не проводилась. |
| Повторяемый локальный запуск | Реализованы README и `.env.example` | Запуск с установленными зависимостями выполнен. Чистая установка по README и замер времени ещё не выполнялись. |
| Скриншоты в отчёте | Завершено | Три файла (`01-api-triage.png`, `02-developer-form.png`, `03-ticket-review.png`) встроены в раздел демонстрации `report.md`. |
| Демо-видео и защита | Не записаны | PDF требует демо 2–3 минуты и отдельную запись защиты 5–7 минут. Для локального пути B скриншоты и логи дополняют видео, но не заменяют его без согласования с куратором. |
| Репозиторий для сдачи | Не опубликован | Рабочая папка находится в личном закрытом хранилище. Для сдачи нужна доступная проверяющему ссылка; публичную копию нужно отдельно подготовить и проверить на секреты/локальные данные. |
| Лог карьерных откликов | Не приложен к отчёту | Это отдельное от MVP приложения задание. Вносить только фактически отправленные отклики. PDF пишет, что отчёт обязателен независимо от числа откликов; 60 откликов дают бонус. |
| Шаблон отчёта | Есть расхождение | Текущий `report.md` использует ранее выбранный пользователем шаблон из 8 разделов; в PDF приведён 10-пунктовый. Нужно подтвердить у куратора, какой формат сдавать. |

## Сквозной сценарий общей темы

| Этап | Состояние |
|---|---|
| Входящее предложение разработчика | Работает через `POST /triage`; реальные почта и чаты не подключены. |
| Перевод и сохранение исходного текста | Работает на проверенном китайском примере; имена студии и игры сохранены. |
| Сбор базовой информации | Двуязычная английская/упрощённая китайская форма связана с исходным обращением уникальным токеном. |
| Внутренняя проверка | Панель сотрудника позволяет дополнять сведения и оставлять отдельную заметку с журналированием события. |
| Финансовые метрики, условия трёх территорий и staff-оценка | Отложены для следующего проекта серии, когда кандидат проходит первичный этап. |
| Карьерные отклики | Не входят в MVP системы по решению Евгении. |
